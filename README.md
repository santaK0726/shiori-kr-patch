# 쿠가야마 시오리의 죽음 수첩 한국어 패치

**일본판 `01007BF026AFC000` + 업데이트 1.0.1(v65536), 개발 시험판 009.** 일본어 본문/UI 슬롯을 사용합니다.

에뮬레이터용과 스위치 Atmosphère용 차분 패키지를 [Releases](https://github.com/santaK0726/shiori-kr-patch/releases)에서 각각 받을 수 있습니다. 원본 게임·키·에뮬레이터 실행파일은 포함하지 않습니다. 본인이 추출한 **패치 적용 전 JP 1.0.1 병합 RomFS 폴더**가 필요합니다.

| 패키지 | 생성되는 폴더 | 확인 상태 |
|---|---|---|
| Emulator Delta | `01007BF026AFC000/Shiori_KR_FULL_DEV_009/romfs` | 수정 Eden에서 초반 캐릭터와 한글 대사 사용자 확인 |
| Switch Delta | `atmosphere/contents/01007BF026AFC000/romfs` | 파일·폴더 정적 검사 완료, 실기 실행 미검증 |

두 패키지는 같은 한글 파일 212개를 생성합니다. 스위치판에는 PC용 Eden 수정 코드가 들어가지 않습니다.

## 만들기

1. 원하는 릴리스 ZIP을 새 폴더에 압축 해제합니다. GitHub의 `Source code.zip` 대신 **첨부된 Delta ZIP**을 사용하세요.
2. Windows x64와 Python 3.10 이상에서 `Apply-Patch.cmd`를 실행합니다.
3. `data` 폴더가 들어 있는 원본 RomFS와 완성본 저장 위치를 선택합니다.
4. 원본 해시·차분 해시와 생성 파일 212개의 해시를 검사한 뒤 완성 폴더를 만듭니다. 원본·설정·세이브는 수정하지 않습니다.
5. 생성 폴더의 `INSTALL.txt`에 따라 설치합니다. 기존 번역 모드는 함께 켜지 마세요.

명령행으로도 적용할 수 있습니다.

```powershell
python patch.py --romfs "원본_RomFS_폴더" --output "새_출력_폴더" --platform emulator
python patch.py --romfs "원본_RomFS_폴더" --output "새_출력_폴더" --platform switch
```

## Eden에서 캐릭터가 보이지 않는 경우

확인된 Windows Eden `de7e6e01d4`에는 RomFS 모드 적용 시 일본어 파일명의 해시를 잘못 계산하는 문제가 있습니다. 번역하지 않은 원본 파일 하나만 모드에 넣어도 캐릭터가 사라졌고, 해시 계산 수정 후 같은 대조판과 009에서 캐릭터가 복구됐습니다.

에뮬레이터 ZIP의 `eden_fix/Create-Fixed-Eden.ps1`은 **정확히 확인된 실행파일 해시만** 받아 원본 옆에 `eden-krfs-fixed.exe`를 만듭니다. 원래 `eden.exe`를 덮어쓰지 않습니다. 다른 Eden 버전은 자동 수정하지 않습니다. [Eden 설치 안내](docs/EDEN.md)를 확인하세요.
