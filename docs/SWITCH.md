# 스위치 Atmosphère용 설치

대상: 일본판 `01007BF026AFC000` + 업데이트 **1.0.1(v65536)**. 본문/UI는 일본어 슬롯을 사용합니다.

생성 폴더 안의 `atmosphere`를 SD 카드 루트에 합치면 다음 구조가 됩니다.

```text
SD:/atmosphere/contents/01007BF026AFC000/romfs/data/...
```

게임을 완전히 종료한 상태에서 복사하고 다시 실행합니다. 동일 게임의 다른 번역/리소스 교체 파일과 섞지 마세요. 이미 같은 위치에 다른 패치가 있다면 사용자가 먼저 별도 위치에 보관한 뒤 이 버전을 적용하세요. 설치 도구가 SD 카드의 기존 파일을 직접 덮어쓰지는 않습니다.

PC용 Eden 해시 수정, ExeFS 실행파일, 키, 본편/업데이트 이미지, 세이브는 포함하지 않습니다. 스위치판의 게임 파일 212개는 검증된 009와 바이트 동일하며 폴더 구조만 다릅니다.

**스위치 실기 실행은 아직 확인하지 않았습니다.** 이 배포물의 스위치 지원 표시는 Atmosphère RomFS 교체용으로 준비했다는 뜻이며, 실기·펌웨어 전반의 작동을 보증하는 실행 결과가 아닙니다. 처음 실행할 때 캐릭터·한글 대사·지도 선택·편의점 진입과 저장/불러오기를 확인하세요.

원래 게임으로 되돌리려면 이 패치로 넣은 `romfs` 파일을 제거하거나 패치 폴더를 SD 카드 밖으로 보관합니다. 다른 모드가 사용 중인 폴더를 통째로 지우지 마세요.

Atmosphère의 공식 RomFS 교체 동작: https://github.com/Atmosphere-NX/Atmosphere/blob/master/docs/components/modules/ams_mitm.md
