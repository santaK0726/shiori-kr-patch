# 에뮬레이터용 설치

대상은 일본판 `01007BF026AFC000` + 업데이트 1.0.1입니다. 본문/UI는 일본어 슬롯을 사용합니다.

1. 게임을 종료합니다.
2. 생성 폴더의 `01007BF026AFC000/Shiori_KR_FULL_DEV_009`를 Eden이 열어 주는 게임의 모드 데이터 위치에 넣습니다.
3. 009만 켜고 이전 PoC·010·011 비교판과 충돌 모드를 끕니다.
4. 아래 수정이 필요한 Eden 빌드라면 수정 사본으로 실행합니다.
5. 새 게임의 캐릭터·한글 대사, 첫 지도 선택, 편의점 진입을 확인합니다.

## 확인된 Eden 해시 수정

Windows x86-64 Eden de7e6e01d4에서 확인했습니다.

1. 원래 Eden을 종료합니다.
2. 릴리스 폴더의 `eden_fix/Create-Fixed-Eden.ps1`에 원본 실행파일을 지정합니다.

```powershell
& .\eden_fix\Create-Fixed-Eden.ps1 -SourceExe "Eden_설치_폴더\eden.exe"
```

3. 같은 폴더에 생성된 `eden-krfs-fixed.exe`로 실행합니다. 원래 바로가기로 실행하면 원본 코드가 사용됩니다.

원본 SHA-256: `cb88b3c8834f5c5cda1cb99d821fa4ce73aaf0adeb423942aca4111aa489bb0e`

수정 SHA-256: `9b38fa5c295ab4a3d5d3736ec580d05a3015be2d19bae4e058f75d0797aa8c87`

파일/폴더 해시 계산의 byte 부호 확장 10곳만 수정합니다. 분기·주소·명령 길이는 같습니다. 다른 해시의 실행파일은 출력 없이 거절합니다. 에뮬레이터 바이너리나 키를 다운로드하지 않습니다.

이 수정은 PC용 Eden에만 적용합니다. 스위치의 게임 실행 코드에는 넣지 않습니다.

해제하려면 번역 모드를 끄고 원래 `eden.exe`를 사용합니다. 생성 도구는 게임 원본·설정·세이브를 수정하지 않습니다.
